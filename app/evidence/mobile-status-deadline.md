# 임시 Mobius 상태 조회 응답 지연 실기기 시험

ROLE: APP · DOC-REV: 2.0.0 · RUBRIC: R03/R10. 2026-10-28 Android 14 공기계에서 debug 앱 SHA-256 `47c2e1f33d65b9764a2f6b8aec4633099b0b1d1288754e34815c178e3995dd6b`를 사용했다. 이 상태 조회는 테스트 전용으로 사용자 인증·실제 권한 또는 장치 관측을 의미하지 않는다.

기존 `tcp:8787` ADB reverse를 통해 loopback 시험 서버에 연결했다. 그 서버는 응답 본문 1바이트를 250ms 간격으로 보내도록 했고, 앱 버튼을 누른 뒤 약 13초에 조회 실패와 버튼 재활성화를 확인했다 ([화면](mobile-status-slow-timeout.png)). 서버에서는 GET 1회와 연결 종료를 관찰했다. 이는 해당 지연 본문 상황의 결과이며, 연결·헤더·쓰기·진행 중인 읽기까지 포함한 엄격한 전체 시간 제한을 증명하지 않는다.

이후 시험 서버만 종료하고 임시 Mobius4 CSE에 연결된 APP 중계를 실행했다. 같은 앱에서 `꺼짐`, `초기값 · 장치 관측 전` 및 조회 시각이 표시됐다 ([화면](mobile-status-deadline-mobius.png)). 이는 bootstrap 초기값의 읽기 결과이지 실제 장치 관측이 아니다. 앱 인증, 운영 API, ACP 및 실물 Gateway는 이 시험에 포함되지 않는다.

시험 종료 후 직접 시작한 중계만 종료하고 이전 앱을 데이터 삭제 없이 복원했다. 휴대폰의 복원된 APK SHA-256은 `bb9dc64aebefbc89c9812b7954181d88e00432ee844e5b8610ba50b463d5ee24`, 기존 `tcp:8787` reverse와 Mobius4 CSE는 그대로 유지됐다. 시스템 인증서 신뢰를 변경하지 않았다.
