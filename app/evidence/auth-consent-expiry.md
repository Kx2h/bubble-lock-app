# 합성 인증 동의 만료 공기계 시험

ROLE: APP · DOC-REV: 2.0.0 · RUBRIC: R03/R10. 2026-10-28 Android 14 공기계와 opt-in debug APK SHA-256 `c6074522fd28ae5d64236055d0b4455c55506b16c9809ebc7ff8575090b8340d`를 사용했다. 테스트 IdP·별도 합성 에이전트·합성 동의 서버만 사용했으며 실제 브라우저, 사용자나 운영 권한을 시험하지 않았다. 테스트 CA는 시험 APK에만 적용했고 시스템·브라우저 신뢰는 변경하지 않았다.

합성 인증 후 상태를 읽고 명시적으로 승인하여 `active`와 120초 유효기간을 확인했다 ([화면](auth-consent-expiry-active.png)). 기기 시계가 표시된 만료 시각에 도달한 뒤 화면은 기존 활성 상태 대신 `기기 시간상 합성 유효기간 경과 · 서버 상태를 다시 확인하세요`를 표시했고 확인 체크와 승인·회수를 비활성화했다 ([화면](auth-consent-expiry-recheck.png)). 이 단계는 실제 권한 만료나 회수의 증거가 아니다.

합성 세션을 종료하고 새로 인증해 상태 조회를 다시 누르자 서버에서 `expired`를 반환했다 ([화면](auth-consent-expiry-confirmed.png)). 기기 시각이 정확하지 않을 경우 이 화면은 잘못된 시각에 재조회를 요구할 수 있으며 서버가 권한의 정본이다. 네트워크 차단 시 실제 만료 여부를 확인할 수 없고, 이 시험은 실제 브라우저·운영 API·ACP를 입증하지 않는다.

시험 서버를 중지하고 에이전트 APK·`18443` 및 `18788` reverse와 UI dump를 제거했다. 기존 앱은 데이터 삭제 없이 설치 APK SHA-256 `bb9dc64aebefbc89c9812b7954181d88e00432ee844e5b8610ba50b463d5ee24`로 복원했으며 기존 `8787` reverse와 임시 CSE는 유지했다.
