# 합성 인증 동의 검토 공기계 시험

ROLE: APP · DOC-REV: 2.0.0 · RUBRIC: R03/R10. 2026-10-28 Android 14 공기계와 opt-in debug APK SHA-256 `9e28e76f547052d31631f5202478c3d08283f91996826c49d787ca1c69a0c276`를 사용했다. 합성 IdP·별도 합성 에이전트·합성 동의 서버만 사용한 시험이며 실제 브라우저, 사용자, 운영 권한이나 인증 증거가 아니다. 테스트 CA는 해당 시험 앱에만 적용했고 시스템·브라우저 신뢰는 변경하지 않았다.

합성 인증 후 `none`을 조회했다. 요청 revision·목적·scope·120초 TTL과 검토 확인 60초 안내를 보았다. 확인을 체크한 뒤 상태를 다시 조회하면 체크가 해제되고 승인 버튼이 비활성화됐다. 다시 확인하고 승인해 `active`가 표시됐고, 회수를 선택해 `revoked`를 확인했다 ([화면](auth-consent-reviewed-revoked.png)).

스크린샷과 이 APK의 `요청 유효기간` 문구는 부정확해, 이후 코드에서 해당 TTL을 `승인 시 유효기간`으로 수정했다. 수정된 문구는 이 실기기 시험에 포함되지 않는다.

검토 시한 경과와 instance·grant 상태·revision·만료 변경은 가짜 시계를 사용한 호스트 게이트 시험에서 검증했다. 기기에서 그 경계나 전송 전 서버 변경을 직접 재현하지 않았으며, 사전 조회와 POST 사이의 경합·운영 권한 검증을 증명하지 않는다. 기존 응답 유실 후 같은 key 재전송과 프로세스 재시작 후 boolean 표시의 동작은 이 시험에서 다시 측정하지 않았다.

시험 서버와 `18443`, `18788` reverse, 합성 에이전트 및 UI dump를 정리했다. 주 앱은 데이터 삭제 없이 기존 APK SHA-256 `bb9dc64aebefbc89c9812b7954181d88e00432ee844e5b8610ba50b463d5ee24`로 복원했다. 기존 `8787` 연결과 임시 CSE는 유지했다.
