# 비인증 합성 동의 화면 만료 시 재조회 공기계 시험

ROLE: APP · DOC-REV: 2.0.0 · RUBRIC: R03/R10. 2026-10-28 Android 14 공기계에서 debug APK SHA-256 `124311394f8ef23bba49c141dc48dbf9caebb036f20631fc05c3daa6ae313a2c`로 시험했다. 이는 인증 없는 고정 합성 요청과 로컬 mock 서버만 사용하는 시험이며 실제 사용자·권한·운영 동의의 증거가 아니다.

서버의 `now()`를 기기 시간보다 90초 이전으로 고정 오프셋 적용했다. 서버 기준 합성 TTL은 120초지만 표시된 `expiresAt`은 기기 시각 기준 약 30초 뒤가 된다. 합성 상태 조회 후 승인하여 `active`를 확인하고 동작 선택 시 회수 버튼이 활성화되는 것을 확인했다 ([화면](unauth-expiry-active.png)). 기기 시각이 표시된 만료 시각에 도달한 뒤에는 기존 active 대신 재조회 안내가 표시되고 체크가 해제되며 승인·회수가 비활성화됐다 ([화면](unauth-expiry-recheck.png)).

이 시험은 기기 시계에 따른 보수적 UI 동작만 확인하며 서버가 실제 `expired`를 반환했거나 운영 권한이 만료됐다고 입증하지 않는다. 시스템 시각이 틀리면 재조회 시점도 달라질 수 있다. 서버 상태 변경 및 응답 유실·프로세스 재시작 시 재전송은 이 시험에서 다시 검증하지 않았다.

시험 후 별도 `18787` reverse와 로컬 fixture, UI dump를 제거했다. 기존 앱은 데이터 삭제 없이 설치 APK SHA-256 `bb9dc64aebefbc89c9812b7954181d88e00432ee844e5b8610ba50b463d5ee24`로 복원했고, 기존 `8787` reverse와 임시 CSE는 유지했다. 기기·브라우저 인증서 신뢰는 변경하지 않았다.
