## 화면 구조 개선

- 시작 화면: 밝은 히어로, 검정 화면 선택 띠, 약속 3가지 띠의 3단 구성으로 바꿨음. 주요 버튼 두 개를 히어로에 둠.
- 가족 화면(휴대폰): 상단 메뉴를 하단 탭 바 5개(홈, 위치, 가족, 권한, 알림)로 옮겼음.
- 운영 개요: 같은 값(lastSequence)을 두 번 보여 주던 지표를 연결 상태 지표로 바꿨음. 명령 행을 누르면 그 명령이 선택된 채로 명령 처리 화면이 열림.
- 공유 권한: 두 폼에 1, 2 단계 번호를 붙여 동의를 만든 뒤 권한을 켜는 순서가 보이게 함.
- 다크 모드: 이전에는 `color-scheme: light`로 고정되어 있었음. 이제 `prefers-color-scheme`를 따름.
- 글자 크기: 10px에서 12px이던 보조 글자를 13px 이상으로, 본문을 17px로 올림.

| 항목 | 결과 |

| `npm run verify` (저장소 루트) | PASS, 13단계 모두 exit 0 (`.local/verification/verify/results.json`) |
| `npm test` (web-dashboard) | 69개 통과, 실패 0 |
| `npm run typecheck`, `npm run build` | 통과 |

`npm run verify` 첫 실행은 `core-tests`의 RBG-03(XSD SHA-256 대조)에서 실패했음. 원인은 이 작업 폴더의 `core.autocrlf=true`가 LF로 커밋된 XSD 6개를 CRLF로 풀어 둔 것이었음. 6개 파일을 커밋과 같은 LF로 다시 풀고 재실행해 통과했고, git 기준 변경은 0건임.
